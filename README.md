# ФотоМастер

Локальный фоторедактор для Android на русском языке. В нём нет рекламы, подписок и водяных знаков, а вся основная обработка идёт на телефоне.

## Что исправлено по сравнению с популярными редакторами
| Жалоба (Snapseed, Lightroom Mobile, PicsArt, Photoshop Express, Meitu, Remini) | Решение в ФотоМастере |
|---|---|
| Водяной знак при экспорте (PS Express, бесплатные версии PicsArt и Meitu) | Водяного знака нет совсем |
| Подписки и платные базовые функции | Всё бесплатно, без аккаунта и без paywall |
| Реклама | Рекламы нет, трекеров тоже |
| Обязательное облако, проблемы синхронизации (Lightroom) | Проекты хранятся локально и сохраняются автоматически |
| Тихое уменьшение размера при экспорте («24 МП → 8 МП») | Экспорт в исходном разрешении по умолчанию, размер виден в диалоге |
| Потеря EXIF (PicsArt) | EXIF копируется: камера, дата, выдержка, ISO, объектив, GPS (GPS можно отключить) |
| Нет истории, только один шаг отмены | Полная история шагов, отмена и повтор, переход к любому шагу |
| Разрушающая правка | Неразрушающая правка: оригинал и стек правок, всё можно изменить позже |
| Пересушенная кожа на «автоулучшении» (Remini, Meitu) | Автоулучшение замечает лица (ML Kit) и обрабатывает портреты мягче |
| Без сети не работает | Все инструменты, кроме сторонних нейросетей, работают офлайн |
| Нет кривых и HSL (PicsArt) | Есть кривые, уровни, HSL по 8 цветам, баланс белого |
| Оригинал перезаписывается | Сохраняется копия в Pictures/FotoMaster |

## Возможности
- Автоулучшение по гистограмме, балансу белого, шуму и лицам. Результат раскладывается на обычные ползунки.
- Кадрирование с пропорциями, поворот на 90°, отражение, выравнивание горизонта.
- Свет: экспозиция, контраст, светлые и тёмные участки, белые и чёрные точки, виньетка, уровни.
- Цвет: температура, оттенок, насыщенность, красочность, HSL, кривые.
- Детали: резкость, чёткость, шумоподавление.
- Слои: рисунок (кисть и ластик, режимы наложения), текст, ретушь (восстанавливающая кисть и штамп), маски с выборочной коррекцией (кисть, радиальная, градиент, «человек» через ML Kit, «небо»), удаление фона (прозрачный, размытие, цвет, ч/б), результат нейросети как отдельный слой, который можно частично стереть.
- 12 встроенных пресетов и свои пресеты.
- Сравнение «до и после»: зажать кнопку или включить шторку.
- Экспорт в JPEG, PNG или WEBP, размер оригинала, 4096, 2048 или 1080.
- На экранах 120 и 144 Гц приложение запрашивает максимальную частоту обновления.
- Можно открыть фото из галереи через «Поделиться» или «Изменить».

## Нейросети: вы всё делаете сами
С версии 1.1.2 приложение не автоматизирует сайты нейросетей. Вкладка «ИИ-промпт» только открывает Qwen (chat.qwen.ai), Алису AI (alice.yandex.ru) или ГигаЧат (giga.chat) во встроенном браузере или во внешнем браузере. Приложение не нажимает кнопки, не вводит текст, не загружает фото и не читает страницу.

1. Напишите запрос и нажмите «Открыть …»: запрос копируется в буфер обмена.
2. На сайте сами прикрепите фото (окно выбора файла открывает системную галерею; кнопка «Сохранить фото для отправки» кладёт текущий вариант в Pictures/FotoMaster), вставьте запрос и сами нажмите «Отправить».
3. Готовую картинку долго нажмите и выберите «Взять в ФотоМастер» или сохраните её и нажмите «Загрузить результат из галереи».

Пользуясь сервисом, вы принимаете его собственные условия.
